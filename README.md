# pairwise-packet-loss-conceal

地铁里听语音，列车进站时声音变成金属嗡鸣，丢一个包后整句重复，蓝牙切换后延迟越来越大：丢包隐藏直接复制最后一个基音周期，进站噪声被当成基音，输出金属嗡鸣；基音估计窗长固定，女声和童声被估成低音；帧长和编解码器绑定，切到 20ms 帧后隐藏时长错位；解码器延迟没从抖动缓冲扣除，PLC 补的帧和后续帧重叠；前向纠错只保护头部，连续丢包时全是伪造帧；DTX 静音期没有舒适噪声，恢复时爆音；采样率切换后 PLC 状态没重置，旧基音延续到新流；瞬态丢包按周期复制，鼓点和爆破音被抹平；淡出淡入在隐藏帧上做两次，音量凹陷；收发两端时钟漂移，抖动缓冲越积越深；蓝牙设备切换后输出延迟变化，PLC 按旧延迟对齐；立体声两个声道独立隐藏，左右相位不一致；连续丢包超过上限后静音，恢复第一帧没有淡入。audio/packet_loss_conceal.py 是核心，tests/test_packet_loss_conceal.py 15个红。要修的是：基音检测；自适应窗长；帧长适配；解码延迟；FEC 范围；舒适噪声；状态重置；瞬态保护；单次淡化；时钟跟踪；设备延迟；双声道同步；恢复淡入。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
